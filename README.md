# Bacheca demo

Versione statica di prova di Bacheca, pubblicata con GitHub Pages: <https://pompeotanga-rm.github.io/bancheca-demo/>.

Le board create qui sono salvate nel browser del dispositivo. Non vengono sincronizzate con il Mac o con altri dispositivi. Le anteprime complete dei link richiedono il server locale e non sono disponibili in questa versione statica. L'interfaccia mobile è ancora da verificare e ottimizzare.
